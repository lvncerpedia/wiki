# Math

数、量、図形、構造、変化といった抽象的な概念を、記号や論理を用いて研究する「抽象的な科学」。

## 1. 現代数学の「4大分野」（最も一般的な分類）現在の数学は、主に以下の4つの大きな柱に分けられます。

### 代数学（Algebra）：「構造」や「数そのもの」を調べる

- 数論：素数や整数の性質を研究する（暗号技術に応用）。
- 線形代数学：行列やベクトルを扱う（AIや3Dグラフィックスに応用）。
- 群論・環論・体論：対称性や計算のルールそのものを抽象化して研究する。

### 解析学（Analysis）：「変化」や「連続性」を調べる

- 微分積分学：変化の割合や、面積・体積を求める。
- 微分方程式：物理現象や感染症の拡大予測などを数式で表す。
- 複素関数論：虚数（\(i\)）を含む複素数の世界での微分積分。

### 幾何学（Geometry）：「図形」や「空間」を調べるユークリッド

- 幾何学：学校で習う、平らな空間の図形。
- 微分幾何学：曲がった空間を微分を使って研究する（アインシュタインの相対性理論に応用）。
- トポロジー（位相幾何学）：切ったり貼ったりせずに、伸ばしたり縮めたりしても変わらない性質を研究する（「ドーナツとコーヒーカップは同じ」とする分野）。

### 統計学・確率論（Statistics & Probability）：「不確実性」や「データ」を調べる

- 確率論：偶然起こる出来事の法則性を考える。
- 統計学：大量のデータから特徴や未来の傾向を導き出す（データサイエンスの基盤）。
